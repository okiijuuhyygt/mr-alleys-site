# EP97〈媽媽還在的時候〉成效與留言（2026-11-04 抓）

IG Reel：觀看 131,820、觸及 101,387、收藏 2,964、分享 4,967、79 則留言（近期最高）。
Reel 只放了四件事的開頭（錄聲音＋實驗、問以前的事、一起做飯、拍照）；Podcast 完整版另外有「更小的事」：幫她按按手、在外面牽她的手、找一天讓她什麼都不用做。

留言重點（轉述，不寫帳號、不逐字引用）：
- 讚最多：錄聲音很重要，聲音很容易隨著時間忘記
- 很多人後悔沒多錄聲音、影片；有人說相簿容量不夠時先刪了家人的影片，現在很後悔
- 有人問：錄影會不會比錄音更好
- 有人說：發現自己也不知道媽媽喜歡做什麼
- 有人說阿嬤不會打字，都傳語音，反而留下很多聲音
- 很多人說「已經來不及了」「她走了」
- 少數人跟家人關係不好，看了反而難受
- 不一定是媽媽：爸爸、阿公阿媽也有人提
