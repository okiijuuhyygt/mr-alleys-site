先講答案：想用 Suno 做 6/8、7/8 這種非 4/4 的拍子，不要在 prompt 裡碰運氣，進 Suno Studio 用 Time Signature（拍號）功能直接設定，這是目前唯一穩的做法。這篇順便講幾個 Studio 更新後我每天在按的功能，還有一招 Logic 裡救律動的小技巧。

## 拍號問題：進 Studio 直接設，別交給 prompt 許願

早期 prompt 裡寫 6/8 常常沒用，模型多半還是回你 4/4。這跟 Suno 生出來的曲風跟你想的不一樣是同一種脾氣（[三個常踩的雷](/blog/se04-002/)），結構性的東西交給文字描述，本來就是碰運氣。現在 Studio 支援 Time Signature，6/8、7/8、12/8 這些都能直接指定，想做華爾滋感、或那種搖擺的三連拍律動，設好拍號再生成，穩很多。記住這條分工：結構性的東西交給功能設定，別交給 prompt 許願。

## Remove FX 和 Warp Markers，Studio 更新後我最常按的兩個

一個是 Remove FX（移除效果），一鍵拿到相對乾淨的 stems，拉進 DAW 重混時空間感自己控，不用跟 AI 硬加的殘響打架，這步之後接的混音處理可以看[我的插件處理順序](/blog/se04-009/)。另一個是 Warp Markers（時間標記，類似 Ableton 的時間拉伸），某一句唱得太趕或太拖，拉一下標記就能把它對齊到格子上，不用整段重生。以前遇到節奏跑掉只能整段重刷，運氣不好刷十次還不對，現在改一個地方就解決，省下的時間很有感。

## 律動對不上？Logic 的 Groove Track 大法

遇過 Suno 的木吉他是 shuffle（搖擺）但整個 band 是 on-beat（正拍），兩邊卡在一起很尷尬。我的救法是在 Logic 開 Groove Track（律動主軌）：把木吉他設成 Groove Master，其他軌開 Flex Mode 勾選跟隨，伴奏就會去學吉他的律動，聽起來像一團有默契的樂團。這招跟我平常把 AI 生的鼓變成可編樂器的流程是同一套邏輯（[Logic 怎麼把 AI 生的鼓變成可以編的樂器](/blog/se05-006/)）。提醒一句，做這種破壞性編輯前先備份原始軌，留一條退路給自己。

## 常見問答

**Suno prompt 裡寫 6/8、7/8 為什麼常常沒用？**
模型對文字描述的拍號不穩，多半還是回你 4/4。想要準確的拍號，進 Studio 用 Time Signature 功能直接設定，不要靠 prompt 碰運氣。

**Remove FX 拿掉效果之後，殘響要自己補嗎？**
對，這就是它的用意。AI 生成時常常自己疊了一層殘響，拉進 DAW 前先用 Remove FX 清乾淨，空間感自己重新加，才不會跟原本的效果打架糊在一起。

**某一句唱得太趕，一定要整段重生嗎？**
不用，這正是 Warp Markers 存在的理由。抓到跑掉的那個點，拉一下標記對齊到格子上就好，不用因為一句話把整段運氣不好的地方全部重刷一次。
