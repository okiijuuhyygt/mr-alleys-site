先講答案：混音卡在「拖來拖去、開選單」這些碎步上，多半是手太慢拖累了耳朵的判斷。這篇分享幾個我在 Logic Pro 天天在按、真的有省到時間的快捷鍵，還有一個把音軌轉成真正單聲道的小手法，都是做案子累積下來的肌肉記憶，學起來當天就有感。

## 先挑重複次數最多的那幾個開始

不用一次背整張快捷鍵表，先看你自己一首歌會重複做哪幾個動作，那幾個就是你最該練的。我自己最常按的是這四個。

| 快捷鍵 | 功能 | 我什麼時候用 |
|--------|------|-------------|
| Option + U | 把多次錄音／多段整合成一軌 | 人聲錄了好幾個 take、comp 完之後，一鍵合成乾淨的一軌再往下處理 |
| Cmd + R | 複製這一軌、自動黏到結尾 | 要延長 loop、把一段 riff 接龍下去時最快 |
| ；（分號） | Move Region to Playhead | 把選到的 region 精準對到播放頭，不用手拖對半天 |
| ／（斜線） | Reverse 開關 | 快速做反轉音效、reverse reverb、進段落前的 riser |

這四個看起來很基礎，但它們省掉的是「開選單、找選項、拖來拖去」那些碎步。這些碎步真正耗掉的是注意力，注意力一散，判斷就開始歪。

## 把一軌變成真正的單聲道

Logic 裡「聽起來像單聲道」跟「真的是單聲道」不一樣。要真的轉單聲道，我會掛 Imaging → Direct Mixer，把它拉到 0。這在處理 bass、kick 這種需要釘在正中間的低頻軌時很重要，低頻散在左右會相位打架、吃掉 headroom（低頻要不要收窄、高頻要不要拉寬，[Mid-Side 是什麼](/blog/se09-004/)那篇講得更完整）。

這個做法比用 Gain plugin 的 mono 鍵更直覺，而且你看得到自己把左右收到多窄，心裡有數。

## 為什麼快捷鍵值得花時間背

我早期混一首歌可以耗一整天，回頭看，很多時間是花在拖來拖去、翻選單的碎步上，耳朵都還沒累，人先煩了、判斷也開始歪。把這幾個變成反射動作之後，手不用離開重點，注意力才留得住。工具順了，判斷力才有空間發揮，這件事比買一堆新外掛實在多了。

## 常見問答

**這些快捷鍵記不起來，一定要一次全背嗎？**
不用。先挑你自己一首歌裡重複次數最多的那兩三個練，練到肌肉記憶，比硬背整張表有效果得多。

**一定要轉真的單聲道嗎？聽起來像單聲道不行嗎？**
人耳對低頻的方向感本來就分不太出來，但左右沒真的收乾淨，相位還是會打架，吃掉你的 headroom。轉單聲道花不到一分鐘，值得做。

**除了快捷鍵，還有什麼方法能讓混音整體變快？**
把 Logic 的偏好設定先調順手也很有幫助，我自己開新專案第一件事就是改這些（見[新裝 Logic 我第一件事會改的幾個偏好設定](/blog/se02-007/)）。工具順了，才有力氣留給耳朵判斷。
