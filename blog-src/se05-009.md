編曲想在段落之間放一個「拉升」或「掉落」的過門音效(transition,銜接兩段的效果聲),在 Splice 或取樣庫用中文搜常常找不到。訣竅是用英文加上具體的功能字去搜。我把常用的關鍵字按功能整理在下面,直接複製去搜就行。

## 拉升 / 掉落

- **Riser**——build-up 一路拉升到過門或 drop,最常用的一個。
- **Downlifter / Downshifter**——往下掉的過門。
- **Synth Drop / Sub Drop / Drop**——啟動過門、落點那一下。

## 增加移動感、落點重擊

- **Whoosh**(可搜 Dramatic Whoosh)——增加移動感跟深度。
- **Impact / Boom / Hit**——落在 drop 上的那一記重擊。
- **Reverse / Reverse Cymbal**——反轉的鈸,經典的 build-up 前置聲。
- **Laser / Laser Beam**——風格化一點的 riser。
- **Sweep / Uplifter / Transition FX**——通用的過門掃頻。

## 搜冷門素材的通則

不只是過門,搜任何冷門素材都是同一套邏輯:用英文、用具體描述,別用中文。舉個例,想找中國風的鳥叫,搜 eagle、hawk、bird asian、guzheng 這種英文具體字,比打「老鷹」有效太多。

取樣庫的標籤幾乎都是英文寫的,你講它聽得懂的語言,它才找得到東西給你。搜之前先想一下:這個聲音,做這個包的人會怎麼命名它?從那個角度下關鍵字,命中率會高很多。
