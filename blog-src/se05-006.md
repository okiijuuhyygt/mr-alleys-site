先講答案：拿 Suno 或任何 AI 生出來的鼓，是一整條混在一起的音檔，你沒辦法一顆一顆改，但用 Logic Pro 的「切片變 sampler」功能，可以把它拆成一組取樣樂器，每一個鼓點變成一個 pad，之後就能用 MIDI 隨便重編節奏，想抽掉哪顆、想加什麼都行。在一個 Y2K 風格的案子裡，我常用的就是這招。

這篇先講怎麼切、切的時候要注意哪三個設定，再講如果只想換掉某一軌音色（不動節奏）該怎麼做，最後講最常踩的一個雷。

## 核心動作：切片變 sampler

Track 選單 → Convert Regions to New Sampler Track，快捷鍵 ⌃E。對話框裡有三個重點：

- **Create Zones From 選 Transient Markers**（讓每個鼓點各自變成一顆 sample），不要選 Regions，那會把整條當成一顆。
- **Instrument 選 Drum Machine Designer**（Logic 內建的 16 格 pad 鼓組介面）。
- **勾 Create 1Shot Zones**，鼓的 sample 播完就停、不會 loop。

切完之後，Logic 還會順手幫你生一條 MIDI，記錄每個切片原本的時間點，直接播就是重建版的原鼓。這條 MIDI 就是威力所在，你可以拿它改節奏、只留 kick、變速不變調。AI 生的鼓常常是這樣一整條音檔焊死的（這其實跟[AI 音樂為什麼分軌拆不乾淨](/blog/se04-004/)是同一個根本問題），切片變 sampler 就是繞過這個限制的做法。

## 想換掉某一軌的音色：Audio 轉 MIDI

如果某一軌（例如 hihat）你想保留原本的節奏跟力度，只是想換成更好聽的 sample，用 Track 選單 → Replace or Double Drum Track，快捷鍵 ⌃D。它會分析每個 transient（鼓點的瞬間衝擊）生成 MIDI，而且力度（velocity）會跟著原音的響度走，不是死板板的固定值。

一個常被忽略的設定：Threshold 要放寬到 −30dB 左右，預設的 −12 太嚴格，小聲的鼓點會偵測不到。

## 常踩的雷：切出來只有一顆

如果切完只有一個 pad 有聲、其他全空，幾乎都是 transient 偵測失敗。看對話框那行小字，如果寫「from 1 selected transient markers」，看到那個 1 就中了。

解法：先把軌道的 Flex 模式打開（任一種都行，Slicing 最常用），雙擊 region 進 Audio File Editor，按 Cmd+T 強制重新偵測一次，marker 對了再回去按 ⌃E。順帶提醒，這兩個對話框會記住你上次的設定，每次切之前都檢查一遍，不要相信它預設就是對的。把 AI 生成的東西拆開重編之後，後面要不要再處理人聲或整體質感，可以參考[Suno 生出來的歌聲很數位、很毛](/blog/se05-003/)那篇的做法。

## 常見問答

**切片變 sampler 跟直接錄一組真鼓有什麼不一樣？**
切片保留了 AI 原本的音色跟細節，只是把節奏解放出來讓你能改；真鼓是完全重做一次力度跟音色。案子趕、只是想調整節奏或抽換幾顆鼓的時候，切片快很多。

**Transient Markers 跟 Regions 選錯了會怎樣？**
選 Regions 的話整條音檔會被當成一顆 sample，你拖 MIDI 上去也只會整條一起播，跟原本沒兩樣，等於白切。一定要選 Transient Markers 才會逐顆拆開。

**切完的 MIDI 音符對不上原本的鼓點怎麼辦？**
通常是 transient 偵測本身就抓錯位置，不是切片這步的問題。回到 Audio File Editor 手動拖 marker 對齊，或先把 Threshold 調整過再重新偵測一次，對齊了再切一次通常就準了。
