先講答案：如果你的 Logic 突然播放變慢、音高整個往下掉，像怪物在講話，先別懷疑專案壞了，十之八九是你剛接了藍牙耳機（尤其 AirPods），把整個系統的取樣率從 48kHz 降到了 16kHz。到 Settings 把輸出切回 Mac 內建喇叭，確認正常後再切回耳機，大多數情況就回來了。頑固的話，終端機重啟一次 Core Audio 就好。

## 先照這個順序救場

遇到這個狀況，我自己每次都是這樣處理：先去 Settings > Audio，把 Output 改成「MacBook Pro 揚聲器」，按 Apply，確認聲音正常了，再切回 AirPods。九成情況這樣就好。還不行，我會開終端機打 `sudo killall coreaudiod`，把 Core Audio 重啟一次，它會自己重開，不用怕。再不行就開內建的 Audio MIDI Setup，確認 AirPods 的 Format 停在 48kHz。

## 為什麼藍牙耳機會讓 Logic 慢下來

原理其實不複雜。AirPods 一連上，或你剛開完 Google Meet，系統常會把耳機切進「通話模式」（HFP），這時 Core Audio（macOS 管所有聲音進出的底層）的取樣率（sample rate，一秒切多少個聲音樣本，數字越低越糊）就從 48kHz 掉到 16kHz。Logic 還照 48kHz 的時間軸在跑，底層卻只餵 16kHz，播出來自然又慢又低沉。這跟專案檔本身有沒有問題無關，如果你的 Logic 是開檔越來越慢、檔案越來越肥，那是另一件事，可以看[專案檔瘦身怎麼做](/blog/se02-003/)。

## 一勞永逸的預防

最關鍵一條：輸入裝置（Input）永遠鎖在 Mac 麥克風或你的錄音介面，別選 AirPods。只要輸入指到藍牙耳機，系統就會強制切通話模式，災難就是從這裡開始的。另外在 File > Project Settings > Audio 把 Sample Rate 鎖死，專案就不會被外接裝置牽著跑。養成這個習慣之後，我自己這幾年幾乎沒再中過這個雷。

## 常見問答

**只有 AirPods 會這樣嗎？其他藍牙耳機也會？**
會，只要是走藍牙的耳機、麥克風，接上之後系統判斷要進通話模式，都可能把取樣率壓下去。原理跟 AirPods 一樣，處理方式也一樣。

**輸出切回喇叭又切回耳機，音高還是不對怎麼辦？**
先確認你真的有按 Apply、聲音有恢復正常再切回去。還是不對，就直接跑 `sudo killall coreaudiod` 重啟 Core Audio，這個指令很安全，它會自己重新啟動，不會弄丟任何東西。

**這個問題只有錄音、混音時會發生嗎？平常聽歌也會嗎？**
平常用 QuickTime、Spotify 聽歌通常感覺不出來，因為那些軟體會自己跟著取樣率調整播放速度。Logic 這類 DAW 是照專案設定好的取樣率死跑，才會被拖慢、變調，這也是為什麼這個雷幾乎只出現在做音樂的人身上。
