常有人問「一首歌到底怎麼從無到有」。我實際跑的流程是七步:找歌手曲風 → 找伴奏 → 去人聲並定 BPM 跟 KEY → 標段落 → 錄旋律加假語言 → 邊做邊檢視靈感跟技巧 → 最後才填詞。重點是先把骨架立穩,歌詞留到最後。

## 前置:先決定要做什麼歌

第一步是找方向:你想寫給誰唱、什麼曲風。接著找一段合適的伴奏(instrumental / beat)當參考或底,把裡面的人聲去掉,定好 BPM(每分鐘幾拍)跟 KEY(調性)。方向沒定就開錄,通常會做到一半迷路,回頭重來更花時間。

## 中段:骨架先於文字

標好段落——主歌、副歌、橋段各在哪——然後開錄。先用假語言(隨便的無意義音節)把旋律唱滿,把記憶點卡出來。這一段我會一直交替檢視兩件事:這個旋律夠抓耳嗎、技巧上還能怎麼延伸。靈感負責亂試,技巧負責把關,來回幾次骨架就穩了。

## 收尾:最後才填詞

旋律定了、段落順了,最後才把假語言換成真正的歌詞。這時候你已經清楚知道每個音要幾個字、重音落在哪,填起來精準很多,也比較不會踩到倒音。把填詞放到最後,是我這些年少走最多冤枉路的一個習慣。
