副歌想寫得澎湃又不出錯,`F → G → Em → Am` 這組進行幾乎是萬靈丹。它最大的好處是可以「一層一層加料」:陽春版四個和弦就能用,想要張力就把 G 換成 F/G、把 Em 加七變 Em7,聽感立刻厚起來。

## 從陽春到進階,同一組往上疊

- 陽春:`F → G → Em → Am → Dm7 → G → C → C7`
- 加強:`F → F/G → Em7 → Am7 → Dm7 → Dm7/G → C → Gm7 → C7`
- 進階:`F → G/F → Em7 → Am7 → Dm7 → Dm7/G → C → Gm7 → C7`
- 簡化:`F → Em → Dm7 → C`
- 樂團:`F → G → Am → Am` 或 `F → G → Am → C`

同一個骨架,想要細膩就往下面的版本走,想要直接就用上面的。

## 那些「/」是什麼

斜線和弦(也叫分數和弦)就是換低音。`F/G` 是 F 和弦踩著 G 的低音,製造一股往前推的張力,特別適合放在副歌爆發的前一拍。這種和弦是加強版跟陽春版聽起來差一截的主因。

## 新手建議:先陽春再加料

先用陽春版把副歌旋律寫好、唱順,確定它抓耳,再把和弦一個一個換成加強或進階版。順序反過來——先塞滿華麗和弦再硬套旋律——通常會做到卡住。如果是樂團編制,`F → G → Am` 那兩組更乾脆直接。
