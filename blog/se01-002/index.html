混音第一步先把音量調對：gain staging 到底在調什麼、為什麼是 -18 dBFS

陳則皞2026-07-10編曲與混音基礎

混音第一步該做的，不是急著掛一堆 plugin，是把每軌的音量關係先擺對。地基疊穩，後面 EQ、壓縮才有意義。很多人卡在「混出來就是糊」，以為是 plugin 不夠貴、外掛買不夠多——十次有八次，問題其實在最不起眼的那一關：音量根本沒排好。

這篇把「先調音量」這件事拆開講清楚：gain staging 到底在調什麼、為什麼大家都講 -18 dBFS、各軌音量大概落在哪、還有疊軌要照什麼順序。都是我每天在做的事。

gain staging 是什麼？為什麼偏偏是 -18 dBFS

gain staging 講白了就是：控制「進到每一個 plugin 的音量」，別太大、也別太小。我的習慣是讓每一軌的訊號峰值落在 -12 到 -18 dBFS 之間，原因有三個，一個一個講。

第一，-18 這個數字不是拍腦袋來的。數位世界裡 0 dBFS 是絕對天花板，過了就是硬破音（clipping）。而類比時代的參考電平 0 VU（≈ +4 dBu），換算到數位大約就落在 -18 dBFS 附近——這是很多錄音室、很多硬體的校準點。你把訊號放在這裡，等於站在類比器材「原本被設計來工作」的位置上。

第二，甜蜜點。大多數 plugin，尤其是模擬類比硬體的那種（壓縮器、飽和、EQ），它們的演算法是針對某個輸入電平調校的。訊號太大，plugin 一進去就已經在硬拗；太小，它抓不到你要的細節，反而把底噪一起放大。-12 到 -18 這個區間，就是讓 plugin 工作在它最舒服、最像原廠設計的地方。

第三，也是最實際的：留 headroom。你把每軌都塞到接近 0 dBFS，總和疊起來一定爆，而且完全沒空間留給之後的 bus 壓縮、母帶處理。峰值壓在 -15 上下，上面那十幾 dB 的空間，是留給後製和母帶用的。

還有一個習慣，比選數字更重要：一軌經過 plugin 處理後，把音量調回跟處理前一樣大。 為什麼？因為人耳天生覺得「大聲=比較好」。你掛一個 EQ、順手把整體推大了 1、2 dB,A/B 切換的時候就會誤判成「哇這 plugin 有效」——其實它只是變大聲而已。這叫 level-match（電平對齊），做母帶比對、比較 plugin 前後，一定要先做這步，不然你整晚都在被自己的耳朵騙。

各軌音量大概落在哪：一張參考表

下面這張是流行歌常見的音量平衡落點。注意：這是「混音平衡時各軌在整首歌裡的相對位置」，跟上面 gain staging 講的「進 plugin 前的峰值」是兩件事，別搞混。這張表也不是聖經，不同曲風、不同編制都會動——真正重要的是相對關係（誰該比誰大聲），不是把每個數字對死。

樂器音量（dB）一句話定位
Vocal-18主角，整首歌的台積電
Bass-15撐住低頻地基
Kick-19節奏骨架，跟 Bass 分工低頻
Snare-19節奏骨架，給拍點
Melody-20旋律樂器，配角
Perc-25點綴，加律動
Hi-hat-25高頻律動
FX-28氣氛、殘響尾巴

一個判斷心法（康小白講的，我覺得很準）：混音跟一檔 ETF 的成分股很像。人聲是台積電，佔了一半以上的權重；第二到第五大是 Kick、Snare、Bass、主旋律樂器；第三條線之後，一般人的耳朵已經聽不太到，再堆下去就接近雜訊了。所以不要貪心愈編愈多——耳朵好的人也就同時聽得到兩三條線。

疊軌順序：先蓋地基，再放主角，配角最後

我混歌的順序是固定的，這個順序本身就是一種 workflow:

順序這一軌為什麼是這個位置
1大鼓 + 小鼓節奏地基，先讓骨架出來
2貝斯貼著鼓進，鎖住低頻
3其他打擊貼上去跟前兩者一起聽，確認律動
4人聲主角，先把它在空間裡的位置卡好
5旋律樂器配角，等人聲定位確認後再擺

這個順序的邏輯是：先把整首歌的骨架跟主角定位，配角才知道自己該站哪、該多大聲。 鼓和貝斯是地基；人聲是主角，一定要先卡好它的位置（乾濕比、空間、前後距離）；旋律樂器是配角，它的音量和空間都是相對人聲來調的。

反過來做就是災難：人聲位置都還沒定，你就先把弦樂、鋼琴調得滿滿的，等人聲一進來，發現整個中頻打架、空間也不對，前面調的全部要重來。先蓋地基、先立主角，是為了少走這種回頭路。

三個最常見的錯誤

一、沒對齊音量就判斷 plugin 有沒有效。 前面講過的 level-match。你沒把處理前後的音量拉齊，聽到「變好了」很可能只是「變大聲了」。養成習慣：每動一個 plugin，回頭把 output 調回原本的響度再判斷。

二、一次全開、配角先調滿。 新手很容易一開場就每軌掛滿 plugin、每軌都推很大聲。結果就是總和一疊起來全部打架、爆頻。正確做法是照順序一軌一軌疊，每加一軌都跟已經在場的一起聽。

三、以為「糊」是 plugin 不夠貴。 這是最花冤枉錢的誤會。很多聽起來糊、混濁的歌，問題不在外掛不夠高級，是音量根本沒排好、低頻兩三軌在同一個區間打架。先把音量平衡和頻率分工做對，再談要不要換更貴的 plugin。

又快又準，靠的是流程不是靈感

早期我混一首歌可以耗一整天，東調西調沒個章法，調到最後耳朵也累了、判斷也歪了。後來養成固定的 workflow——先 gain staging、照順序疊軌、每步 level-match——速度跟穩定度就一起上來了。

音量平衡這關看起來最不起眼，卻是決定一首歌「聽起來乾不乾淨」的分水嶺。它不需要靈感，它需要的是每次都照同一套流程走。把這關做穩，你會發現後面 EQ、壓縮要動的東西，比想像中少很多。
