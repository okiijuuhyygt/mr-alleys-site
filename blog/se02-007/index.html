新裝 Logic 要先改哪些偏好設定？三個小設定讓你做事快一倍

陳則皞2026-08-05Logic Pro 與 DAW 技巧

先講答案：剛裝好 Logic，我會先進偏好設定改三個地方，讓「選軌道時自動選起整軌的 Region」、打開 macOS 鍵盤導覽（用 Tab 在對話框按鈕間跳）、還有存檔前把視窗放大好讓預覽圖清楚一點。都是小設定，但一整天下來省的滑鼠點擊很有感。

這三個設定花不到五分鐘，做完之後你會發現很多重複的滑鼠動作直接消失。順序我照最常用到的排。

第一件事：選軌道自動選 Region

預設點某一軌，不會順便選起那一軌上的所有片段，搬移、複製整軌都要多框一次。去 Logic Pro > Settings > General > Editing 分頁，勾「Select regions on track selection」就好。

我遇過勾了失效的狀況，取消、關掉設定視窗、重開再勾一次，通常就正常了。這個設定改完最有感，尤其是專案軌道一多、常常要整軌搬移的時候（Logic 專案越開越慢，我怎麼幫它瘦身也是類似的體感問題，都是小地方省下來的）。

第二件事：打開鍵盤導覽，少用滑鼠

匯入匯出檔案時常跳出一堆「取消／儲存／選擇」按鈕，預設只能滑鼠點。去 macOS 系統設定把鍵盤導覽打開，之後這些對話框就能用 Tab 跳、空白鍵確認，手不用離開鍵盤，快很多。

這跟我平常在用的快捷鍵是同一個邏輯：手離開滑鼠的次數越少，做一首歌的時間就越短（我天天在按的那幾個快捷鍵另外整理過，見Logic Pro 我天天在按的幾個快捷鍵）。

第三件事：存檔前放大視窗，預覽圖才看得清

Logic 存檔會把當下的畫面截成一張 Preview.png，你在 Finder 按空白鍵預覽 .logicx 檔看的就是它。解析度是存檔那一刻定死的，所以存檔前我會把視窗最大化、軌道 zoom in 一點，生出來的預覽圖就清楚。

Finder 用 Cmd+4 切成 Gallery 檢視，預覽區也更大，一堆專案要找哪個時很好認。這個習慣特別適合手上案子多、專案檔越存越多的人，找檔案不用一個一個點開來確認。

常見問答

這三個設定要每個專案都改一次嗎？
不用，都是 App 層級或系統層級的設定，改一次全部專案都生效，不用每開一個新專案就設定一次。

Select regions on track selection 勾了沒反應怎麼辦？
先確認你是在 General > Editing 分頁勾對地方，還是失效的話，取消勾選、關掉設定視窗、重新打開 Logic 再勾一次，通常就會正常運作。

鍵盤導覽只對 Logic 有用嗎？
不是，這是 macOS 系統層級的設定，打開之後所有 App 的對話框都能用 Tab 跳、空白鍵確認，不是 Logic 專屬的功能。
