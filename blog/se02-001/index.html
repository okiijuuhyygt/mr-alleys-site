Logic Pro 播放突然變慢、音高變低？八成是藍牙耳機搞的鬼

陳則皞2026-07-30Logic Pro 與 DAW 技巧

如果你的 Logic 突然播放變慢、音高整個往下掉，像怪物在講話，先別懷疑專案壞了——十之八九是你剛接了藍牙耳機（尤其 AirPods），把整個系統的取樣率從 48kHz 降到了 16kHz。到 Settings 把輸出切回 Mac 內建喇叭、確認正常後再切回耳機，大多數情況就回來了。頑固的話，終端機重啟一次 Core Audio 就好。

為什麼藍牙耳機會讓 Logic 慢下來

AirPods 一連上，或你剛開完 Google Meet，系統常會把耳機切進「通話模式」（HFP），這時 Core Audio（macOS 管所有聲音進出的底層）的取樣率（sample rate，一秒切多少個聲音樣本，數字越低越糊）就從 48kHz 掉到 16kHz。Logic 還照 48kHz 的時間軸在跑，底層卻只餵 16kHz，播出來自然又慢又低沉。

我救場的順序

先去 Settings > Audio，把 Output 改成「MacBook Pro 揚聲器」，按 Apply，確認聲音正常了，再切回 AirPods。九成情況這樣就好。還不行，我會開終端機打 sudo killall coreaudiod，把 Core Audio 重啟一次——它會自己重開，不用怕。再不行就開內建的 Audio MIDI Setup，確認 AirPods 的 Format 停在 48kHz。

一勞永逸的預防

最關鍵一條：輸入裝置（Input）永遠鎖在 Mac 麥克風或你的錄音介面，別選 AirPods。只要輸入指到藍牙耳機，系統就會強制切通話模式，災難就是從這裡開始的。另外在 File > Project Settings > Audio 把 Sample Rate 鎖死，專案就不會被外接裝置牽著跑。
