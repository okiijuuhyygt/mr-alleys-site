第一次宅錄要買什麼設備？麥克風、錄音介面，我踩過的雷都在這

陳則皞2026-08-02Logic Pro 與 DAW 技巧

先講答案：第一次在家錄音，硬體先抓兩樣就好，一支電容麥克風、一台錄音介面。安靜房間錄人聲，Rode NT1 這種自噪音極低的大振膜很夠用（記得開 48V 幻象電源）；想帶著到處錄、插上就走，就選 MiC 96k 這類 USB 麥。介面接上 Mac 老斷訊，通常是供電不足，不是壞掉。這篇器材清單的完整版看宅錄要買什麼器材，這裡先講我自己踩過的兩個雷，跟怎麼判斷你該買哪一支。

麥克風怎麼選：先問自己兩個問題

第一個問題，你多常搬。第二個問題，房間多安靜。這兩個答案決定你該買哪一支，不是誰貴。

NT1 是需要幻象電源（48V，由錄音介面供給，電容麥沒它不會動）的大振膜電容麥，自噪音很低，安靜房間裡錄人聲很乾淨，適合固定的宅錄位。MiC 96k 是 USB 麥，直接插電腦就能錄，音質沒 NT1 那麼講究，但方便，適合行動錄音、外景、隨手抓 demo。房間夠安靜、位置固定不動，選 NT1；常常要搬去別的地方錄、或想先低成本試水溫，選 USB 麥。

錄音介面斷訊：先查供電，不是先送修

我遇過 Focusrite 介面接 Mac 一直斷斷續續，查半天才發現是供電不足，不是介面壞掉。排查順序我會這樣做：先換一條線試，再接一台有獨立供電的 USB Hub，或直接插 Mac 的 Thunderbolt 口。順帶一提，M 系列 Mac（像 M3 Max）左右兩側 USB-C 口的供電能力不一定一樣，換個孔有時就好了。遇到斷訊先別急著懷疑介面壞了，九成是這幾步就能解決。

一個容易忽略的設定：輸入裝置鎖好

在 Logic 裡把輸入裝置（Input）鎖在你的介面或 Mac 麥克風，別讓它自己跳到藍牙耳機，一跳，系統會切通話模式，錄進來的聲音品質整個崩掉。這個坑跟播放忽然變慢、音高走鐘是同一個藍牙病灶，詳細原因看Logic Pro 播放突然變慢、音高變低。硬體再好，輸入指錯地方也是白搭，錄之前多看一眼這個設定，能省下重錄一次的時間。

常見問答

麥克風跟錄音介面，預算有限先買哪個？
先買錄音介面。沒有介面，電容麥根本沒電、插不上 Mac；有介面之後，先用內建麥克風或便宜的 USB 麥都能錄，之後再升級麥克風。

錄音介面老是斷訊，是設備壞了嗎？
大部分不是。先換一條傳輸線，再試獨立供電的 USB Hub 或直接插 Thunderbolt 口，M 系列 Mac 換個 USB-C 孔也常常就好了。真的全部試過還是斷，才考慮送修或換一台。

電容麥跟 USB 麥，音質差很多嗎？
在安靜房間、固定位置錄人聲，電容麥（像 NT1）確實乾淨很多。但如果你常常搬動、想低成本先試，USB 麥的方便性換來的音質差距，對剛開始錄的人不會是決定性的問題。
