Logic Pro 我天天在按的幾個快捷鍵，做事快一倍

陳則皞2026-09-04混音進階

混音做久了會發現，真正決定速度的是少繞路，手快不手快其實沒差那麼多。這篇分享幾個我在 Logic Pro 天天在按、真的有省到時間的快捷鍵，還有一個把音軌轉成真正單聲道的小手法。都是做案子累積下來的肌肉記憶，學起來當天就有感。

錄音、剪輯最常用的四個

快捷鍵功能我什麼時候用
Option + U把多次錄音／多段整合成一軌人聲錄了好幾個 take、comp 完之後，一鍵合成乾淨的一軌再往下處理
Cmd + R複製這一軌、自動黏到結尾要延長 loop、把一段 riff 接龍下去時最快
；（分號）Move Region to Playhead把選到的 region 精準對到播放頭，不用手拖對半天
/（斜線）Reverse 開關快速做反轉音效、reverse reverb、進段落前的 riser

這四個看起來很基礎，但它們省掉的是「開選單、找選項、拖來拖去」那些碎步。這些碎步真正耗掉的是注意力，注意力一散，判斷就開始歪。

把一軌變成真正的單聲道

Logic 裡「聽起來像單聲道」跟「真的是單聲道」不一樣。要真的轉單聲道，我會掛 Imaging → Direct Mixer，把它拉到 0。這在處理 bass、kick 這種需要釘在正中間的低頻軌時很重要——低頻散在左右會相位打架、吃掉 headroom（這件事在 M/S 那篇也講過）。

這個做法比用 Gain plugin 的 mono 鍵更直覺，而且你看得到自己把左右收到多窄，心裡有數。

為什麼快捷鍵值得花時間背

我早期混一首歌可以耗一整天，回頭看，很多時間是花在拖來拖去、翻選單的碎步上，耳朵都還沒累，人先煩了、判斷也開始歪。把這幾個變成反射動作之後，手不用離開重點，注意力才留得住。工具順了，判斷力才有空間發揮——這件事比買一堆新外掛實在多了。
