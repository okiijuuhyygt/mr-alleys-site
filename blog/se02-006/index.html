Logic Pro 突然不能 Undo？先看你是不是卡在 Melodyne 或 Flex 模式

陳則皞2026-08-04Logic Pro 與 DAW 技巧

先講答案：Logic 按 Cmd+Z 沒反應、上一步收不回來，先別急著重開軟體，很可能你人在 Melodyne 或 Flex 這類有「獨立 Undo 堆疊」的模式裡。這些外掛的復原步驟跟 Logic 主系統是分開的，你得先在那個外掛裡面 Undo，才回得到你想收的那一步。

先看游標焦點在哪

遇到 Undo 沒反應，我第一件事先看滑鼠焦點停在哪個視窗，而不是急著查資料。如果剛在 Melodyne 裡動音準，就把游標移進 Melodyne 視窗再按 Undo，通常就回來了；Flex（Logic 內建的時間伸縮工具）也是同一招，先點回 Flex 那個區塊再收。焦點對了，Cmd+Z 才會收到你真正想收的動作。

如果確認焦點沒錯、還是收不回來，再往下想是不是剛做了某個本來就不可逆的動作，比如 Bounce 或 Flatten，那些本來就沒有 Undo，只能靠事前存檔補救。

為什麼會這樣：兩套獨立的記憶

Melodyne 走的是 ARA（讓外掛跟 Logic 共用音軌的技術），它自己記一套操作歷史，跟 Logic 主線的歷史分開存在兩本帳上；Flex 也有它獨立的編輯狀態，不會跟 Logic 的其他動作記在同一條時間軸上。當你的焦點在這些區塊，Cmd+Z 收的是 Logic 主線的動作，收不到你剛在外掛裡做的事，看起來就像整個軟體壞了，其實只是你在問錯的那本帳要答案。

這個坑我自己也踩過，修音修到一半按了幾次 Undo 都沒動靜，慌了一下才發現只是焦點還停在 Melodyne 視窗外面。知道原理之後，遇到這種狀況就不會慌，先換焦點試一次就好。

我的排查順序，跟事前預防

我自己養成的習慣是：先確認滑鼠焦點在哪個視窗，對應那個視窗按 Undo；確定不是外掛的問題，再回頭想是不是剛做了不可逆的動作。真正治本的做法是事前預防，大動作之前（進 Melodyne 修一大段音準之前、做 Flex 之前、Bounce 之前）我習慣先 Cmd+S 存一版，真出事至少退得回去，不用整段重錄重編。專案檔如果已經越存越肥、開檔越來越慢，可以看看我怎麼幫專案瘦身，也是同一種先預防再收拾的邏輯。

常見問答

Cmd+Z 完全沒反應，是不是軟體壞了？
大部分不是，是焦點卡在 Melodyne 或 Flex 這種有獨立 Undo 堆疊的地方。先把游標移進那個外掛的視窗再按一次，九成會回來。

Melodyne 裡面按 Undo 也沒用怎麼辦？
先確認你是真的點進了 Melodyne 的編輯區，還是只是選到那個音軌。如果焦點真的在裡面還是沒反應，可能是 ARA 連結本身出問題了，重新開關一次 ARA 連結通常能解。

做完 Bounce 才發現手滑，還救得回來嗎？
Bounce、Flatten 這類動作本來就不進 Logic 的 Undo 堆疊，存檔之後基本救不回來。唯一的解法是事前養成習慣，大動作前先存一版。
