唱歌比賽的伴奏要怎麼準備？調 key、剪長度、格式，一次講清楚

陳則皞2026-09-04常見問題

先講答案：比賽伴奏要準備三件事：一是 key 要對你的音域，二是長度要剪到比賽規定，三是格式跟音量要能在現場直接播。網路上抓的伴奏常常 key 不對、有人聲殘留、結尾沒收乾淨，這些都要在賽前處理好。準備的方式跟計費怎麼算，看你是要重做一版還是用手上現成的，諮詢時直接問。

賽前三件事

  1. 調 key：先確定你唱這首最舒服的 key，伴奏整首移調，不要只是把你的聲音硬撐。
  2. 剪長度：多數比賽限 90 秒到 3 分鐘，剪的時候留前奏兩小節讓你進歌，結尾要有收，不要突然斷掉。
  3. 格式跟音量：WAV 或 320k MP3，音量不要壓到爆，交給主辦前自己用手機跟喇叭各播一次。

比賽前一週的檢查

  • 用比賽現場同款的設備試播一次，至少用外接喇叭不要只聽耳機。
  • 檔名寫清楚：歌名、你的名字、key。
  • 備一份在手機、一份在隨身碟。

常見問答

我手上有一版伴奏，但 key 不對，可以處理嗎？
可以，諮詢時把檔案帶來，聽過就知道能不能移調、還是要重做。

要比賽或 cover，怎麼計費？
看是重製一版還是用現成的，以及要不要錄音。這些在諮詢時談，沒有固定價目。

伴奏的授權要注意什麼？
用在比賽跟 cover 的授權，跟你拿到伴奏的來源有關，諮詢時一併問清楚。
