副歌和弦怎麼配？F-G-Em-Am 這組萬用進行，從陽春版到進階版怎麼加

陳則皞2026-08-13詞曲創作與唱歌

先講答案：副歌想寫得澎湃又不出錯，F → G → Em → Am 這組進行幾乎是萬靈丹，而且它最大的好處是可以一層一層加料，陽春版四個和弦就能用，想要張力就把 G 換成 F/G、把 Em 加七變 Em7，聽感立刻厚起來。

先挑版本：陽春、加強、進階、簡化、樂團，怎麼選

同一個骨架，往下面走越細膩，往上面走越直接：

  • 陽春：F → G → Em → Am → Dm7 → G → C → C7
  • 加強：F → F/G → Em7 → Am7 → Dm7 → Dm7/G → C → Gm7 → C7
  • 進階：F → G/F → Em7 → Am7 → Dm7 → Dm7/G → C → Gm7 → C7
  • 簡化：F → Em → Dm7 → C
  • 樂團：F → G → Am → Am 或 F → G → Am → C

怎麼選看你在做什麼階段。旋律還沒定案，先用陽春版把副歌旋律寫好、唱順，確定它抓耳。旋律確定了，再一個一個把和弦換成加強或進階版，加料加到你覺得夠厚就停。如果是樂團編制、現場要好抓好跟，F → G → Am 那兩組更乾脆直接，不用堆疊太多。這個「先簡單再加料」的順序，也是我自己寫歌卡關最常拿出來用的救法之一。

那些「/」是在幹嘛

斜線和弦（也叫分數和弦）就是換低音。F/G 是 F 和弦踩著 G 的低音，製造一股往前推的張力，特別適合放在副歌爆發的前一拍。這種和弦是加強版跟陽春版聽起來差一截的主要原因，光是低音換一個音，整組和弦的方向感就變了。

新手最常犯的錯：順序反過來

先陽春再加料，這個順序不能反。我看過最多人卡住的狀況是先把和弦寫得又滿又花，F/G、Em7、Gm7 全部一次上，結果旋律怎麼套都套不進去，因為和弦已經先占滿了空間。正確的做法是先確定旋律好不好聽、順不順口，和弦永遠是為旋律服務，不是反過來讓旋律遷就和弦。這跟和弦進行卡住怎麼辦裡講的邏輯是同一套，先求穩，再求變化。

常見問答

F-G-Em-Am 這組進行為什麼這麼多流行歌在用？
因為它從第一個和弦到最後一個和弦，張力一直在往前推，很容易讓副歌聽起來有推進感，而且四個和弦都是最基本的三和弦，新手也彈得出來。

陽春版跟進階版可以混著用嗎？
可以，而且我自己常常這樣做。比如前半段副歌用陽春版打底，唱到後半段要疊得更滿的時候才換進階版，聽感上會有一種越唱越滿的效果。

分數和弦聽起來都差不多，一定要用嗎？
不一定。分數和弦是拿來做張力用的，如果你的歌本來就走簡單直接的路線，樂團編制、現場感重，用陽春版或簡化版反而更合適，不用為了聽起來厲害硬塞。
